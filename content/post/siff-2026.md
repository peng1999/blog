上班之后感觉就真没啥时间写博客了，特别是技术类的博客，感觉随着 AI 的发展已经越来越不再有价值。不过至少每年上影节，我还是希望写一点文字进行记录。

今年上影节总共看了九部电影，今年的排片第一次引入了 Vibe coding，让 AI 帮我写了一个求解器，针对转场时间，新老片配额，类型配额等多种约束进行了规划求解。总的来说今年我对我的观影日程规划还是很满意的。下面的电影会给出三种评级：A —— 值得一看的好电影，B —— 中规中矩，C —— 在上影节看这种片就是浪费时间。

# 寻找薇薇安·迈尔 { .movie-heading }

*Finding Vivian Maier*

评级：B

2024 年豆瓣排名第六的纪录片。讲述了一个生前默默无闻的，以保姆为生的摄影师，在身后被重新发现的故事。这么说或许不是特别准确。整个影片的基调，还是大量的访谈，试图还原出薇薇安迈尔生前的经历。配以她本人大量的照片作为佐证。薇薇安的故事的确动人，具有传奇色彩，但是我其实更感兴趣的是她的照片是如何获得认可的，策展人是如何让整个项目在经济上可持续的。

# 重制 { .movie-heading }

*Remake* 2025

评级：B

上影节的第二部记录片，主要是导演和他儿子的家庭影像。从儿子的小时候开始拍起，一直到青年时期，到最后戒毒失败失去生命。这部影片作为一部记录片来说确实还不错，对于影像进行了非常有机的组织。但是我由于缺乏相关生命经验，情感上难以和影片共鸣。

# 爱上平行时空的你 { .movie-heading }

*Сводишь с ума* 2025 俄罗斯

评级：C

豆瓣 8.0 的俄罗斯高分作品，但是我不是很感冒。比起斯拉夫人的热情奔放，我果然还是更喜欢日本人的含蓄一些。而且这部的结尾可以算得上是粗糙，男主最后莫名其妙都到女主的时空了，那么这个时空出现了两个男主咋解决，也没有交代。类似题材的《你的名字》剧作结构就好很多。

# 生日快乐 { .movie-heading }

<span dir="ltr"><bdi dir="rtl"><em>عيد ميلاد سعيد</em></bdi> 2025 埃及</span>

评级：A

开门见山的好片子。讲述了在埃及，一个从事家政服务童工的 8 岁小女孩托哈一天之内的故事。故事紧凑，节奏张弛有度。

电影的第一幕到第二幕，舞台从富人社区直接切换到了贫民窟。这样的情节安排立刻让人联想到了《寄生虫》。但是它又巧妙地从孩童的角度切入。主人公机智、勇敢，但是又有着属于这个年龄的单纯。整个第二幕到第三幕结尾，小女孩坐在回到贫民区的公交上，终于认清了阶级之间巨大的鸿沟，完成了她的成人礼。

# 桃色公寓 { .movie-heading }

*The Apartment*

评级：A

无可质疑的经典老片，我相信任何人都会被这部电影的剧本所折服。即使电影的故事梦幻到有些不真实，但当影片末尾《友谊地久天长》响起，谁又不愿意看到一个有情人终成眷属的结局呢？

# 风暴边缘 { .movie-heading }

*Stormbound* 2026

评级：B

正如同 IMAX 所宣传的那样，我们不是在欣赏这部电影，而是置身其中。激光 IMAX 的放映条件下，声音画面给人的震撼是极大的。

# 最后之熊 { .movie-heading }

*Der letzte Bär* 2026 德国

评级：B

以为是政治惊悚，没想到却是一部黑色喜剧片。不知道为什么，这部电影让我脸盲症犯了，前半部分完全分不清两个女角色谁是谁，人物关系怎么样。很难说得到了特别好的观影体验。

# 迷失的露西 { .movie-heading }

*Lucy Lost* 2026 法国

评级：A

受到地缘政治影响，今年上影节没有日本电影。这使得今年的动画片单可选项不多。我最终在动画竞赛单元中选择了我最感兴趣的《迷失的露西》，整届电影节只买了这一场动画片。令人惊喜的是，它没有辜负我的期望，一举拿到了金爵奖最佳动画。这部片子我也非常喜欢。

影片的故事开始于一个与大陆隔绝的小岛。失忆的主人公露西从这里开始，经历了一系列事件，逐渐找回自己的过去。影片非常有技巧地控制了信息的释放，随着故事的进展，谜团不但没有解开，反而越来越多。直到最后的高潮，谜底揭晓，所有的爱、隐瞒、保护和痛苦都得到了答案。

在一个儿童片的框架下，影片架设了一战这一沉重的背景。全片反复讨论着各种身份认同问题：敌人和同胞的认同，家人和外人的认同，以及最重要的自我认同。每一种身份都在某处被推翻，但最终又得到了再确认。

# 世界的主人 { .movie-heading }

*세계의 주인* 2025 韩国

评级：A

在上影节的最后一场。讲述曾经的受害者如何去面对过去的创伤。似乎也是今年上影节唯一的一部韩国电影。影片本身当然是议题新颖，质量上乘，反而感觉没有什么可多评价的了。
